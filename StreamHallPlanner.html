Customer SLA—▸
SLA boundary = the binding constraint at each temperature: RH-max curve vs. dew-point cap (whichever is lower) on top, RH-min vs. dew-point floor on the bottom. Leave dew-point cap blank for an RH-only box. All boundaries recompute at site pressure. ASHRAE TC 9.9 reference ramp limits: 9°F/hr (5°C/hr) where tape media is present; 36°F/hr (20°C/hr) otherwise.

Sensor Validation6 external reference methods▸
Field-check temperature and RH sensors against an independent physical reference. Six methods, each showing the true value and its uncertainty — a verdict is only as good as the reference behind it. See docs/sensor-validation.md for when to use which.
Wetted wick, ≥3 m/s airflow. The instrument reads the psychrometric wet bulb; Eq. 35's thermodynamic one differs by ~0.5 %RH, systematically.
For sites with a chilled-mirror or other dew-point meter — reference-grade when the mirror is clean. RH follows from Tdb and Tdp alone (pressure-independent).
A saturated-salt jar is an absolute reference — physical chemistry, nothing to drift or expire — and its realized accuracy is set by how well you know the chamber temperature. NaCl barely cares (−0.04 %RH/°C); Mg(NO₃)₂ moves −0.30 %RH/°C. Sealed jar, slurry with visible solids, sensor above the slurry, hours to equilibrate. Reference: Greenspan (1977), NBS.
Crushed ice + a little distilled water — slush, not floating cubes. Stir, wait 2 min, keep the probe mid-bath off the walls. Reference: 32.0 °F / 0.00 °C by definition.
Rolling boil, probe mid-water off the pot. The reference is computed from this site's pressure — water does not boil at 212 °F at altitude. Impurities and superheat limit a field check to about ±0.9 °F.
Side-by-side with a recently calibrated instrument at the same spot, both settled. The verdict band widens by the reference's own uncertainty — a comparison can never be better than the reference.
Enter readings to compute the reference value.
All methods run at site pressure — where pressure matters. Verdict bands: RH ±2% PASS / ±5% MARGINAL (typical capacitive spec); temperature ±0.9 °F PASS / ±1.8 °F MARGINAL — each widened by the reference's stated uncertainty, shown with every verdict.
